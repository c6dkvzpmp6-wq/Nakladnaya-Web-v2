Накладная Web v2
Откройте index.html в браузере или загрузите его на GitHub Pages.
Поставщик вводится вручную. Товар: название + артикул одной строкой.
Сумма позиции = количество × закупочная цена.
Бюджет, потрачено и остаток считаются автоматически.
Данные сохраняются в localStorage браузера.
Голосовой ввод использует SpeechRecognition, если браузер его поддерживает.
